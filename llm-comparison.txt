My Model vs. LLM Model Comparison:
Comparing the models I wrote in `models.py` with those in `robot-models.py`, I noticed some stark differences. I prompted ChatGPT to prioritize “complexity and thoroughness,” which clearly influenced the output/code. Each of the classes in `robot-models.py` has many more attributes; for example, Course includes a location, timezone, capacity, and status (whether the class is in draft form, active, completed or archived). The LLM model also added validation logic through clean() methods and helper methods such as mark_accepted() in QRCodeUpload, which checks that the scanned QR code matches the lecture, that the student is enrolled, and that attendance is currently open. Some of these additions are genuine improvements over my model (e.g., enforcing that students can only submit attendance once per lecture), but I believe that the LLM also included unnecessary attributes (and the assignment is to create a simple app), such as requiring a rejection reason in QRCodeUpload, or fields like IP address. The LLM  also generated an abstract base class “TimestampedModel” for reusable timestamps, as well as auto-generated the QR code identifier, which I did not consider. Overall, the LLM code is more complete but harder to read and harder to implement, because every record requires more fields and extra validation logic would likely produce more bugs. My model is simpler and easier to build on incrementally, while the LLM’s is closer to a final, production-ready system able to handle a large and complex institution’s attendance data.
